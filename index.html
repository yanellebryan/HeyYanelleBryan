01 — About

A little bit about me

Hey! I'm Yanelle Bryan A., a Computer Science student at the University of St. La Salle who builds things that actually get used. My work spans mobile development, computer vision, full-stack web systems, and game development — wherever the problem takes me.

I led the development of ParkAlisto, an intelligent parking ecosystem selected to represent the Negros Island Region at the CHED RAISE 2026 National Summit. I also built Baskety, a full POS system with hardware barcode sensor integration currently deployed at a real mart in Bacolod City, and MathVille Ventures, an educational city-builder game played by elementary students at USLS.

Beyond building, I've served as an IT Intern at Negros Power, worked as Lead Project Manager at Collektyv handling international clients, and held leadership roles in the CS Society at USLS. I thrive at the intersection of real-world impact and clean, thoughtful engineering.

Things I've built

Real-world systems designed to solve real problems — from smart parking to intelligent retail.

ParkAlisto — Computer Vision

CHED RAISE 2026 National Summit Presenter

A smart parking detection system focused on real-time parking slot monitoring, designed to improve efficiency and reduce time spent searching for spaces. As the project lead and conceptualizer, I guided the development of this system which utilizes computer vision to detect available spaces and provides a web-based dashboard for real-time occupancy monitoring. The project proudly represented the Negros Island Region at the CHED RAISE 2026 National Summit.

Python Computer Vision Web Technologies Firebase YOLO

ParkAlisto — Mobile App & Admin

A full-featured smart parking ecosystem consisting of a Flutter mobile application and a web-based admin panel. Users can book slots, scan QR codes, and track real-time countdowns. The admin dashboard handles walk-in management, thermal receipt printing, live slot mapping, and booking analytics. Backed by Firebase Firestore and Cloud Functions.

Flutter Web App Firebase QR Scanner Cloud Functions Real-time DB

Baskety — POS System

Successfully Deployed & In Use

A comprehensive mini mart grocery store inventory configuration and point-of-sale (POS) management system, currently deployed and actively used in a real mart in Bacolod City. Features a user-friendly dashboard for analytics, robust product management, inventory control, and a dedicated interface with hardware barcode sensor integration for processing fast sales transactions efficiently.

Python Django Barcode Sensor Inventory POS

MathVille Ventures

Successfully Deployed at USLS Elementary

An interactive educational city-builder game developed in Unity, designed to merge critical mathematical learning with fun, intuitive gameplay. Players expand their own bustling metropolises by solving varied math challenges; after solving a math question, players must locate the correct answer on the map to be rewarded with points. The game was successfully deployed and played by elementary students at the University of St. La Salle, where it generated immense engagement and positive educational outcomes.

Unity Engine C# Game Development EdTech UI / UX
