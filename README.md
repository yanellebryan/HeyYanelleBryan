## 🚀 About This Repository

This repository contains the source code for my personal portfolio website. It was designed from scratch to reflect my skills, projects, and professional journey as a developer. The site features a modular architecture, responsive design, dark/light mode, and custom-built animations.

### ✨ Key Features
- **Modern UI/UX**: Glassmorphism design with a dynamic, animated background and smooth scroll reveals.
- **Theming**: Fully functional Light/Dark mode toggle that persists user preference.
- **Modular Codebase**: Clean, maintainable structure splitting CSS, JS, and layout.
- **Responsive & Accessible**: Optimized for all screen sizes and mobile devices.

## ⚙️ Running Locally

If you'd like to run this portfolio locally to check out the code or the animations:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yanellebryan/HeyYanelleBryan.git
   cd HeyYanelleBryan
   ```

2. **Run the local development server:**
   I've included a custom Python script to serve the site.
   ```bash
   python3 run.py
   ```

3. **View in browser:**
   Open your browser and navigate to `http://localhost:8000`
